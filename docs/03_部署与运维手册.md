# SAP B1 10.0 通用审批平台部署与运维手册

本手册指导如何将通用审批平台部署到 Windows Server / 本地环境，并完成与 SAP B1 10.0 及第三方辅助平台的配置联动。

---

## 1. 部署拓扑与准备工作 (Prerequisites)

```text
[SAP B1 客户端 (内嵌 Web 控件)]
       │
       ▼ (HTTP/HTTPS)
[Approval.Api + Web 静态门户] (端口: 5000) ───► [ApprovalDB (SQL Server 2022)]
       ▲
       │ (轮询 Outbox 事件)
[Approval.Worker 守护进程] ───(REST)───► [SAP Service Layer (端口: 50000)]
```

### 运行环境要求：
- **操作系统**：Windows Server 2019 / 2022 / 2025 或 Windows 10/11 (x64 / ARM64)
- **运行时**：.NET 8.0 Runtime (Hosting Bundle)
- **数据库**：Microsoft SQL Server 2019 / 2022
- **SAP 端**：SAP Business One 10.0 SQL Server 版，Service Layer 服务正常运行

---

## 2. 数据库部署 (ApprovalDB)

> [!IMPORTANT]
> **物理隔离原则**：审批平台必须使用独立的 `ApprovalDB` 数据库，**严禁在 SAP 公司库 `DB_KCC` 中混建审批表**，防止破坏 SAP 原生表结构与升级兼容性。

### 步骤：
1. 打开 SQL Server Management Studio (SSMS)。
2. 新建独立数据库：`ApprovalDB`（排序规则：`Chinese_PRC_CI_AS`）。
3. 执行初始化脚本：
   - 打开文件：[`database/01_init_approval_db.sql`](file:///C:/repo/SAP_B1_10.0/%E8%87%AA%E5%AE%9A%E4%B9%89%E5%AE%A1%E6%89%B9/approval-platform/database/01_init_approval_db.sql)
   - 确认文件编码为 **GBK**。
   - 执行脚本创建 12 张核心表及并发唯一索引。

## 3. 服务端部署方式 (二选一)

### 方式一：全自动一键部署 (推荐)
以管理员身份打开 PowerShell，执行：
```powershell
cd C:\repo\SAP_B1_10.0\自定义审批\approval-platform
pwsh deploy/deploy-to-server.ps1 -TargetServer 127.0.0.1 -ServicePort 5000
```
该脚本会自动：
1. 运行自动化测试与编译构建；
2. 校验并初始化 `ApprovalDB`；
3. 将 `Approval.Api` 和 `Approval.Worker` 注册为自动启动的 Windows 服务；
4. 自动放行防火墙端口。

---

### 方式二：手动配置与运行
1. **修改配置文件**：
   - 打开 `dist/win-x64/Approval.Api/appsettings.json`，配置连接字符串与 Service Layer 地址：
   ```json
   {
     "UseInMemoryDb": false,
     "ConnectionStrings": {
       "ApprovalDbConnection": "Server=127.0.0.1;Database=ApprovalDB;User Id=sa;Password=123456@a;TrustServerCertificate=True"
     },
     "SapAdapter": {
       "Mode": "ServiceLayer",
       "ServiceLayer": {
         "BaseUrl": "https://127.0.0.1:50000/b1s/v1/",
         "CompanyDb": "DB_KCC",
         "UserName": "manager",
         "Password": "YourPassword",
         "MirrorEnabled": true
       }
     }
   }
   ```
2. **启动服务**：
   - 启动 API 宿主：`Approval.Api.exe --urls=http://0.0.0.0:5000`
   - 启动后台 Worker：`Approval.Worker.exe`

## 4. SAP 客户端与第三方辅助平台配置

由于辅助平台为无源码黑盒，需按照平台已具备的配置项完成以下两项配置：

### 4.1 型号订单窗口 (`CHORDR`) 动态 URL 配置
1. 在辅助平台中打开“型号订单”窗体设计器。
2. 窗体右侧放置一个 **WEB 浏览器控件**。
3. 窗体上配置一个命令按钮“【审批详情 / 提交】”，配置动作选择**“刷新表头数据”**，并在 Web 浏览器赋值表达式中填入：
   ```text
   http://192.168.134.9:5000/index.html?companyAlias=DB_KCC&objectCode=CHORDR&objectKey=[$[DocEntry]]
   ```
4. 保存配置。用户在 SAP 中打开任意型号订单时，点击该按钮即可在内嵌 Web 控件中看到该单据的审批状态与审批轨迹。

### 4.2 统一审批工作台（无对象窗口）配置
1. 辅助平台新建一个“无对象窗口”，命名为“待办审批工作台”。
2. **左侧放置 SAP 查询表格**：
   - 数据源绑定 SQL 查询：查询 `ApprovalDB.dbo.wf_task` 及 `@CH_ORDR` 表。
   - 单号列配置为**“文本框（带链接）”**，链接目标窗口指向“型号订单”，取值列指向当前行的 `DocEntry`。这样用户点击单号左侧的**黄色箭头**即可直接在 SAP 客户端打开该单据！
3. **右侧放置 Web 浏览器控件**：
   - 动态加载工作台首页：`http://192.168.134.9:5000/`。
   - 用户可直接在右侧网页进行同意/拒绝审批，左侧点击黄箭头联动查看原始单据，达成完美闭环。

## 5. 运维监控与故障排查

1. **健康检查与接口文档**：
   - API Swagger 地址：`http://<服务器IP>:5000/swagger`
2. **日志与追踪排查**：
   - 系统所有日志均自动输出全链路 `TraceID`。在前端页面或 API 报错时，只需复制日志中的 `TraceID` 即可在系统日志中精准过滤出全链路调用堆栈。
3. **网络闪断与补偿自愈**：
   - 当 SAP Service Layer 临时重启或闪断时，审批操作会安全保存在 `ApprovalDB.dbo.wf_outbox` 中，Worker 会自动采用指数退避算法进行重试，连接恢复后自动同步。
